DESCRIPTION:
    DeskSim is a small scale web application to help students and people learing IT help desk understand basic ticket interaction workflows they may experience. The application displays a small collection of mock up tickets that are catorgorized with numbers, issues, categories, statuses, and descriptions.
    All ticket information is stored in a local JSON file and loaded using JavaScript fetch method. Users can view all tickets or filter them by their status. The application displays the number of tickets within each filter status.
    The project was built using HTML, CSS, JavaScript, and JSON and the interface was insprired by early Web 1.0 design aesthetic while keeping accessibility features in mind.

HOW TO RUN:
    1. Download the DeskSim project folder.
    2. Open the project folder in VS Code.
    3. Run the project with Live Server extension for VS Code.
    4. Open index.html in the local server to a web browser.
    5. use the Filter by Status dropdown to display all tickets or filter them by their current status
